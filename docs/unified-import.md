# 统一导入：上传、预览、确认

导入入口现在自动读取文件，不再要求先选择支付宝或微信、再点击一次预览。支持选择文件、选择文件夹、拖入文件，以及粘贴剪贴板中的文件。混合来源可一起上传。

## 识别和账户

文件名是线索，正文标题、导出账户、卡号和表头共同确定来源。已支持支付宝 CSV/Excel、微信 CSV/Excel、建行 XLS，以及本次提供的农行、招行电子 PDF。正文明确指向另一平台时，错误的来源选择不能通过。

每个文件在预览中显示来源、涉及的资金账户、明细和处理结果。明细每页 25 条，原始字段展开时生成；分页不影响全量校验和确认，待核对记录可直接定位。账户按每行的支付方式匹配，微信/支付宝一份账单可涉及多张银行卡和余额账户。本方完整卡号用于区分银行账户；同银行尾号唯一匹配时给出账户建议。多个账户共用尾号会要求在当前预览中选择，不能靠尾号强行合并。当前兼容实现会暂存账户绑定；PIRC-9 目标写入只保存 `bill_fact.account_code`、对应 `bill_raw` 证据以及必要的 ACCOUNT Review，不保留独立绑定表。

缺少资金渠道时显示“未提供资金账户”，可以在预览里选择账户；不会把文件名当作具体卡号。尚未识别的来源也可在同页选择，不增加独立向导步骤。

## 交易与来源证据

多源能力最终只能写入 PIRC-9 已约定的三张 Fact 表：

- `import_file`：文件来源、机构、SHA、覆盖期间和导入计数。
- `bill_raw`：每次导出的原始行、解析状态、来源引用及其 `bill_id`；同一事实可以拥有多条原始证据。
- `bill_fact`：唯一、规范化且金额使用整数最小单位的事实。

合并分支使用的 `accounts`、`account_bindings`、`import_evidence`、
`import_identities`、`import_previews` 只是当前迁移期实现，不属于 PIRC-9
目标模型，必须在目标写入完成后删除。预览改用有界、过期的应用命令状态，
不作为账本 SQL 表。

文件 SHA 负责重复文件，交易身份负责不同文件中的重复交易。备注、商品说明、客户摘要和交易方展示名称不进入平台交易唯一键。银行无交易号时，结合本方账户、日期、金额、余额及同文件内重复次数处理；同日同额的多笔真实交易不会简单折叠成一笔。

跨渠道支付只有在同一张卡、同日同额、银行渠道证据相符，而且双方候选唯一时才自动关联。两个实际账户之间的转账仍是两笔资金变化。缺乏身份信息或有多个候选时，预览内提供“补充已有流水 / 保留为新交易”，而不是无声丢弃或重复入账。

强交易标识相同但日期或金额冲突会阻止确认。已有字段及人工决定不被补充文件覆盖；缺失字段保留补充证据，日期级记录可以补充已知的秒级时间。流水详情列出各个原始文件及其字段。原始文件没有提供的秒数不会在界面伪装成真实的零点时间。

## 状态和金额

金额解析、校验和身份比较使用整数分；既有 Bill 金额接口保持兼容。建行导入另核对文件声明的收入与支出合计。

已关闭交易保存为原始记录，不新建已发生收付。完整支付和退款分别保留，退款不算普通收入。理财/账户转移保留原始性质，不自动当成普通消费。“微信零钱通转出到银行卡”按零钱通流出处理，银行入账为另一账户的流入。

全部原始记录可在导入弹窗的“最近导入记录”查看，包括没有创建流水的已关闭交易。已经保存过的同一文件再次上传不会增加记录。完成提示分别列出新增、补充证据、非收付记录和重复跳过数量；全部重复时明确说明本次未新增入账。

## 确认和兼容

一次确认按整个批次事务提交。预览与确认绑定版本；期间账本变化会要求刷新同页预览。并发重复确认返回同一结果，核心唯一约束兜底。未解决错误的批次不会部分导入。

密码仅用于本次解包，不进入预览状态或证据。确认使用服务端解析结果，无需再次输入密码。未确认预览 24 小时失效；目标实现的预览属于应用命令状态，不进入长期账本 SQL。

旧 `/api/imports/{source}` 接口仅在迁移开发期间保留。由于当前没有生产数据，目标写入和 API/UI 切换完成后直接重建空数据库，不保留 23 张旧表或 5 张合并兼容表。

```powershell
.\.venv\Scripts\python.exe scripts/verify_intake_ui.py
.\.venv\Scripts\python.exe reports/verify_smart_samples.py --commit --sequential --reverse
```

后两项使用本机 `E:\Worktable\Download` 样本，浏览器验证额外需要 Playwright 和 Edge，验证数据库使用临时目录。`scripts/import_test_samples.py` 会实际写入 8765，供本次独立测试账本初始化使用。

当前范围：电子文本 PDF，最多 100 页；单文件 25 MB、单批约 100 MB、最多 100 文件；一个有效 Excel 明细工作表；ZIP 内一个受支持文件；人民币。扫描 PDF、未知银行版式、其他币种或关键身份字段不足会在预览明确指出，不能宣称任意银行任意格式均可无误识别。
