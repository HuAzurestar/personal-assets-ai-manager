# PIRC-9 功能覆盖与验收记录

本记录以《PIRC-9 个人账单可信底座 MVP 需求分析》和《方案设计》为验收入口，代码口径为 `review-foundation-v2`。

## 事实层

| 需求 | 实现 | 验证 |
| --- | --- | --- |
| 支付宝/微信预览、确认、逐文件结果 | `/api/imports/{source}/preview`、`/batch/preview`、确认接口及 Web 导入向导 | `test_import_formats.py`、浏览器导入回归 |
| 稳定流水、原始字段、文件/批次/行追溯 | `Bill`、`LedgerOrigin`、`ImportBatch`、`ImportArtifact`；`/api/transactions/{id}/source` | 来源回查及回钻测试 |
| 文件指纹去重、文件事务、批量隔离 | `(source_type, sha256)` 唯一索引；单文件一次提交，批量逐文件提交 | 重命名去重、约束回滚、批量前后文件继续导入测试 |
| 错误和缺失字段显式可见 | 异常行保存原始字段、行号和错误，但不生成正式 `Bill`；修正/排除动作追加审计 | 异常行修正、驳回、重新核验测试 |
| Facts 不物理删除，密码不持久化 | 删除 API 固定拒绝；ZIP 密码仅请求内传给解析器 | 删除拒绝、密码 ZIP 与浏览器存储检查 |

## 修订层

| 需求 | 实现 | 验证 |
| --- | --- | --- |
| 标签、分类、账户修订及撤销 | 标签状态审计、账户修订链、期望版本和反向审计 | 修改、撤销、旧版本冲突、原始来源不变测试 |
| 重复、个人转移、代收代付 | 候选仅建议；重复明确保留项；个人转移需不同本人账户；代收代付使用手工事项分配 | 候选详情、批量原子性、冲突与撤销重算测试 |
| 退款逐笔分配及撤销 | 分配、性质和审计分表；单条撤销，不删除历史 | `60`、`60+40`、超限、方向、并发和忙锁测试 |
| 未确认/已撤销不进入正式口径 | 汇总只读取当前有效事项、决定和分配 | 建议、稍后、忽略、撤销前后重算测试 |
| 写入幂等且未知字段不静默忽略 | 确认与撤销使用唯一幂等键；严格 Pydantic 写契约 | 重试只产生一条审计、异参冲突、未知字段 `422` 测试 |

## 增强层

| 需求 | 实现 | 验证 |
| --- | --- | --- |
| 一个有效流水集合 | 列表、dashboard 和回钻共用 `_ledger_clauses`；确认排除决定映射到 `aggregate_excluded` | 组合筛选 ID 集合一致测试 |
| 收入、支出、退款抵扣、净额、数量 | `_ledger_summary` 基于整数分贡献重算，不写回 Facts | 退款跨期、部分分配、手工事项和金额精度测试 |
| 时间、账户、来源、收支、标签筛选 | 三个查询入口使用同一筛选参数和返回的 `filters` | 组合筛选、分页和标签规模测试 |
| 完整回钻 | 返回来源、标签/账户修订、事项全部版本、候选动作、退款性质/分配审计及排除依据 | `test_drilldown_contains_complete_revision_evidence` |
| 口径和生成时间可见 | dashboard 与回钻返回 `basis_version`、`generated_at`、筛选范围和组成 ID | 有效账本契约与浏览器回钻回归 |
