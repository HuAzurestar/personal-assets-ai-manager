# 四类明细与详情工作区

本次按用户确认的设计统一事实流水、账本流水、审查记录和导入文件。

## 阅读与交互

- 打开详情时保留原列表 DOM、筛选、页码及滚动位置。1200 CSS px 起显示当前列表页的紧凑记录栏，支持上一条、下一条；全屏模式隐藏记录栏。较窄视口使用单栏。
- 详情先展示业务标题、金额、状态、紧凑统计，再展示交易字段与关联。主要业务区默认展开，技术信息、原始载荷和历史默认折叠。
- “展开全部业务信息”仅展开业务区，不自动请求每条关联或展开技术载荷。关联集合每页 20/50/100 条，显示全量计数。
- 关联对象可原位加载其业务详情。继续追溯时“转为主详情”，记录返回路径及正文滚动位置，避免递归弹窗或无限嵌套。
- 当前列表页的上一条/下一条不跨服务端分页；页边界禁用相应按钮。返回列表可换页。
- 短视口让标题和正文一起滚动，保留内容空间。明细列表在窄屏转换成带字段名的记录块。
- 账户 hash 不作为名称；缺少名称明确显示“账户名称未识别”，原值可在技术信息中查看与复制。明确带时区的时间统一转换为 UTC+8；未注明时区的值保留原记录时间，不推测偏移量。
- 金额保留币种精度，缺失信息不伪装为零；原始摘要、文件名不改写。ID、批次码、SHA 和原始键保留在技术区。

## 关联与金额口径

- Allocation 仍是 Review、Fact、Ledger 的三元关系。展示以“来源事实／所属审查／分配去向／金额”解释每条记录。
- 当前金额只统计 `review_case.status == 0` 的分配；撤销历史可读但不参与当前合计。
- 单独打开已撤销审查或失效账本时，默认展开它自身的历史分配并明确标记，避免主对象的全部关系都被折叠。事实页混合的历史分配仍默认折叠。
- 事实详情展示当前有效分配及与事实金额的差额；账本展示本条金额与来源事实比例；审查按完整币种单位和方向分组；文件只统计本文件关联事实对应的有效分配。
- `CNY` 与 `CNY_4` 不合并，流入与流出不互相抵消，不计算跨币种总额。
- 文件“成功行数”与“去重关联事实数”是不同口径。关联文件之间可能共享事实，因此文件汇总不应跨文件直接相加。
- 撤销后恢复默认覆盖可能保留原残余分配并新增恢复分配；不能假设每个事实始终只有一条有效分配。

## API 扩展与查询边界

- `GET /paam/ledger/v1/flow/list` 的每行仍对应一个账本记录，新增 `display_summary` 和 `effective` 展示字段。摘要由唯一 Allocation 指向的 Fact 取得，状态由其 Review 取得。分页后一次有界批量查询，不逐行加载详情。详情中的账本对象使用同样字段口径。
- 审查列表新增 `display_summary`、`fact_count` 和 `allocation_count` 展示字段，通过当前页的一次批量查询取得。单事实且标题与交易方完全相同的自动命名优先展示来源摘要，原始标题保持不变；其他手工标题优先保留。详情采用相同回退规则，原始标题可在技术信息查看。
- `GET /paam/import/v1/import_file/{id}` 新增 `relation_summary`：有效审查数、分配数、账本数，以及按 `currency_code` 和 `entry_direction` 分组的整数金额。采用文件来源行到事实 ID 的半连接，重复来源行不重复计算金额。
- 文件的 `/transaction_fact/list` 继续返回全部关联事实和总数，保持现有非分页关系集合契约；浏览器只对展示分页。普通 PO 列表仍由服务端分页。
- Fact 详情的来源证据新增 `raw_payload` 与 `issue_message`，原始字段只在详情返回、折叠展示，不进入列表和统计查询。
- 未改变数据库表结构、导入写入逻辑、Review 状态机、金额分配规则或标签归属。
- 已知时间边界：虽然表字典定义 UTC，当前来源解析器使用无时区 `datetime.strptime`，写入器直接采用该值，API 同样返回无时区时间。本次界面不能据此断言源时间为 UTC；对既有记录做时区规范化需要独立的数据口径与迁移工作。

## 验证入口

`python src/script/verify_inspection_ui.py --matrix --samples E:/Worktable/Download`

脚本使用临时 SQLite 与临时应用端口；不写入日常账本。测试包括真实样本关联链路、合成的撤销/分配场景、关系分页、同页展开与返回、宽高比及逻辑视口矩阵。DPI 和浏览器缩放以逻辑视口与像素密度模拟，不代表实机多显示器人工验收。

截图只在显式传入 `--screenshots` 时输出，使用合成验收记录。金融样本内容不打印或写入仓库报告。
