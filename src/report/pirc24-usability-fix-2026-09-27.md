| 优先级 | 问题 | 修复 |

| P1 / F02 | 编辑判断内容时没有提前告知旧建议失效 | 动态区分改名/计划/启停与判断变更；读取待确认数量，展示修订递增、取消和重扫影响，确认后才保存；冻结原始版本令牌 |
| P2 / F03 | 配置开关、当前运行及上次结果混在一起 | 独立显示配置开关、排队/分析/暂停/阻塞/服务未开启及原因；提供状态流转说明 |
| P2 / F04 | 历史 accepted_count 被误称为“已启用” | 改为“累计通过”，明确包含后来被替换的建议，不冒充当前生效数 |
| P2 / F05 | 候选预览仅有代码和内部编号 | 改名“查看待分析账目”；中文原因、游标后最多 100 条/样例最多 20 条、商户/摘要/金额/时间与只读账目详情 |
| P2 / F06 | 建议详情缺少决策上下文与操作影响 | 顶部当前→建议标签对照、理由和操作；同账目同维度其他建议、取消/替换影响及可分页的完整范围列表 |
| P2 / F07 | 设置嵌套卡片、技术信息与普通配置同等突出 | 三个主分区：模型连接、数据披露、运行概况；高级参数和诊断折叠，密钥管理集中在编辑弹窗，金额用日常单位，移除产品中的 M2 演示入口 |

规则列表按钮明确分工：规则详情＝配置与执行结果；查看待分析账目＝本地只读筛选；编辑规则＝改变配置与判断内容。长 Prompt 收为单行摘要，累计统计去除五个独立卡片。

接口按 Router、Ledger、write-concurrency 技能边界实现：仅为现有预览响应追加摘要字段；SQL 留在 Mapper；样例一次批量查询，不逐行读数据库；预览无模型调用、游标/标签/申请写入；保存仍用展示时的 expected_updated_time，不自动重试覆盖。
