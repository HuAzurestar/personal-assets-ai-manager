# 四类明细与详情改造验证

## 实现结果

事实、账本、审查与文件共用响应式详情工作区。主区域显示可读业务信息、有效金额和关联摘要；技术标识及原始证据折叠保留。支持同页关联展开、转为主详情、返回上层、当前列表页上一条/下一条、全屏切换和关系集合分页。窄屏列表采用带字段名的记录布局。

账本列表补充来源摘要与生效标记；审查列表补充摘要、事实数和分配数；文件详情补充有效关系计数及按币种精度/方向分组的金额。当前分配和已撤销历史明确分开。账本详情展示标签，并保留账户和标签编辑入口。

设计与接口口径见 [详情工作区说明](../doc/inspection-workspace.md)。

### 其他边界

- 所有账单导入与状态变更发生在脚本创建的临时数据库，日常账本未被修改。临时数据库在测试结束后清理。
- DPI/浏览器缩放通过逻辑视口和像素密度模拟；不是对多台物理显示器的人工舒适度验收。低于 320 CSS px 的极窄视口只对详情做退化可用性验证。
- 文件关联事实接口按既有契约返回完整集合，界面分页控制渲染数量，不是服务端关系分页。
- 原始时间存在历史口径问题：导入器和 API 返回无时区值。界面保留这些原值，不伪造 UTC 偏移；对已有数据做时区规范化不属于此次展示改造。
- 原有账务模型、正式分配规则、审查写事务和源事实均未改变。
