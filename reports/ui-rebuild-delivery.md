# UI 重构交付

## 原问题与本次处理

| 问题 | 重构结果 |
| --- | --- |
| 导入、筛选占满页面，手机看不到账目 | 流水优先；导入独立面板；高级筛选默认折叠；手机流水卡片。 |
| 选择与执行不一致，导入失败原因丢失 | 文件/平台变化使预览失效；逐文件预览；重复和错误项跳过；结果逐项说明。 |
| 标签管理缺少基本操作 | 新增、重命名、归档和恢复维度/标签；支持单条及批量修改。 |
| 保存失败丢输入，页面失败仍显示旧内容 | 保存成功才关弹窗；失败可重试；页面加载有明确状态，过期响应不能覆盖新页面。 |
| 页面返回丢条件，翻页停在列表底部 | URL 保存查询；前进后退恢复条件；翻页回顶部。 |
| 已确认转移筛选漏项 | 后端兼容筛选同时覆盖个人/他人转移；中文状态展示。 |
| 原始记录在普通列表难找回 | 增加所有/有效/已排除范围及排除标识、原始详情；不改变原有汇总默认口径。 |
| 数据库反复进入后多次翻页 | 一次绑定事件；每次操作只发送一个分页请求。 |
| 768px 控件遮挡、手机候选横向拖动 | 统一响应式布局；小屏导航保留中文；候选以纵向证据卡片展示。 |

## 风格

四种风格均已实现：清爽青绿、克制蓝灰、暖白纸感、深色专注。按用户选择默认采用 04 深色专注，在 `/#settings` 可即时切换并保存到当前浏览器；表格、弹窗和手机端同步应用。独立风格卡仍可在 `/static/style-cards.html` 查看。

视觉以浅底、清晰边界和主次按钮为主；不把装饰加入账务流程。保留品牌图标，导航使用单色线条图标与中文文字。

## 实现范围

- 新工作台：`app/static/ledger.js`、`ledger.css`、`app/templates/index.html`。
- 服务端：兼容扩展流水范围、候选状态筛选及原子批量标签合并。未删除原始记录、未改变默认收支聚合规则。
- 风格卡：`app/static/style-cards.html`。
- 回归：`tests/test_ui_contract.py`、`scripts/verify_ui.py`。
- 当前演示服务：`http://127.0.0.1:8767`；35 条构造账目及 2 组候选，存于独立的 `data/ui-rebuild/`。

## 验证与边界

后端与既有测试共 31 项通过。真实 Edge 浏览器回归涵盖文件切换、重复导入、ZIP 密码、保存失败恢复、导航历史、标签维护、批量标签、候选处理撤销、排除记录追溯、加载失败重试、重复进入数据库页翻页，以及五页在 390/740/768/1024/1440px 下的布局。结果和截图见 `data/ui-verification/`。

本轮没有连接真实远程 LLM，也未宣称所有真实账单变体或超大数据量都经过验证。存在依赖弃用和 SQLite 表达式索引反射警告，未导致本轮回归失败。后续新增能力继续沿用原始流水与审计保留的约束。
